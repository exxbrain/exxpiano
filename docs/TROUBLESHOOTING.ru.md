# Диагностика

[English](TROUBLESHOOTING.md) | Русский

Все эти случаи реально встретились при разработке.

## Статус служб и журналы

```bash
rc-service exxpiano status; rc-service exxpiano-fx status
grep ' exxpiano: ' /var/log/messages | tail -30          # синтезатор (тег — имя службы)
grep ' exxpiano-fx: ' /var/log/messages | tail -30       # мост механики
grep 'supervise-daemon' /var/log/messages | tail -10     # служба, программа которой завершилась и была запущена снова
aconnect -l          # клиент «FLUID Synth» должен быть, клавиатура подключена
vcgencmd get_throttled
free -m
```

В журнале `exxpiano-fx` должны быть строки `synth: FLUID Synth …` и `input: <ваша клавиатура> …`. Службы — это службы OpenRC (`rc-service <имя> restart`); их вывод попадает в системный журнал `/var/log/messages` (при ротации — `messages.0`).

## Нет звука

| Симптом | Причина и решение |
|---|---|
| `exxpiano: no sound card found` на Raspberry Pi 5 | У Pi 5 нет разъёма 3,5 мм: подключите USB-звуковую карту или аудиоинтерфейс (плата играет только через него) |
| `aplay -l` пишет «no soundcards found» | Штатный звук выключен: `dtparam=audio=on` в `/boot/usercfg.txt` (образ его включает; `config.txt` принадлежит пакету загрузчика и перезаписывается при его обновлениях), `reboot` |
| `exxpiano` постоянно перезапускается (в журнале снова и снова `supervise-daemon … exited`) | FluidSynth сразу выходит, если его вход закрыт. Запускайте его только через `/opt/exxpiano/exxpiano-run` (служба так и делает): скрипт держит открытым канал только для root как вход FluidSynth. Не используйте `-s` (режим сервера): он открывает управляющий порт на всех сетевых интерфейсах |
| В журнале `Out of memory`, процесс `Killed`; в разделе «Монитор» web-интерфейса в ошибках «out of memory: the kernel killed fluidsynth» | Банк не помещается в память (у Pi 3 A+ 512 МБ). В разделе «Банк рояля» web-интерфейса выберите `piano-lite.sf2` (образ его содержит и на такой плате выбирает сам) или соберите пресет `lite`. Подробности: `dmesg \| grep -i oom` |
| `aconnect -l` не показывает «FLUID Synth» | `exxpiano` не запущен или ещё грузит банки (десятки секунд после старта) |
| Клавиатура играет, механики нет | Не загружен `mech.sf2` (проверьте `MECH_SF2` в `/etc/exxpiano.conf`) или не запущен `exxpiano-fx` |
| Звук есть, но очень тихий | Поднимите `GAIN` (для этих банков 1.0) и громкость ALSA (`alsamixer`, F6, Headphones ~90%) |
| При аккордах хрип | `GAIN` слишком большой, уменьшите |
| В журнале `Failed to find an audio format supported by alsa` | Карта открыта напрямую (`hw:...`) и не принимает 16-битный стерео (USB-интерфейсы часто дают только 32 бита / 4 канала). Используйте форму `plughw:` или оставьте `ALSA_DEVICE=auto` |
| После подключения или отключения USB-карты звук идёт не с того выхода | `rc-service exxpiano restart` (автоматический перезапуск через eudev не проверялся) или задайте `ALSA_DEVICE` явно |

## Щелчки, задержка

- Сначала `vcgencmd get_throttled`. Если не `0x0`, это питание, а не настройки (см. README).
- Щелчки: увеличьте `PERIODS` до 3–4 (или `PERIOD_SIZE`).
- Задержка: `PERIODS=2` на штатном выходе, лучше USB-карта.
- Нагрузка: `htop` (поток `fluidsynth` у 100% — берите `lite`, уменьшите `POLYPHONY`, держите `REVERB=0`; на Pi с 4 ядрами `CPU_CORES=3` делит голоса между ядрами).

## USB-накопитель не предлагается для импорта банка

| Симптом | Причина и решение |
|---|---|
| Карточка «Банки с USB-накопителя» пишет, что накопитель не подключён | Накопитель не смонтирован: посмотрите `grep exxpiano-usb /var/log/messages` и `lsblk -f`. Файловая система должна быть FAT32, exFAT или ext4 (не NTFS); Pi должна уметь запитать накопитель (помогает хаб с питанием) |
| Накопитель виден, но «нет папки piano-banks» | Папка должна лежать в корне накопителя и называться ровно `piano-banks` |
| Папка пуста | Предлагаются только обычные файлы `.sf2` / `.sf3` (без `mech.sf2`, без `.sfz`, без ссылок, скрытых файлов и вложенных папок) |
| Импорт не удался | Сообщение говорит почему: не годный SoundFont, не помещается в память, мало места на карте, накопитель извлечён |
| Правило не срабатывает | Запустите вручную от root: `python3 /opt/exxpiano/exxpiano-usb.py add /dev/sda1` (имя раздела смотрите в `lsblk`). Правило eudev (`/usr/lib/udev/rules.d/90-exxpiano.rules`) на реальном железе не проверялось |

## MIDI-файлы не играют

| Симптом | Причина и решение |
|---|---|
| Раздел «MIDI-плеер» пишет, что проигрыватель не работает | Проигрыватель — часть моста механики: `rc-service exxpiano-fx status`, `grep ' exxpiano-fx: ' /var/log/messages` |
| «Играть» ничего не делает, карточка пишет, что синтезатор не запущен | Дождитесь загрузки банка (около минуты после перезапуска) и нажмите «Играть» снова |
| Импорт не удался | Сообщение говорит почему: не стандартный MIDI-файл, слишком большой (4 МБ), слишком длинный (30 минут), слишком много событий, мало места |
| Файл играет без стука молоточков и педали | Механика та же, что у клавиатуры: проверьте её уровни в разделе «Туше и механика» |
| В плотной пьесе пропадают ноты | Полифония ограничена: увеличьте её в «Звуковой выход» или возьмите банк полегче |

## Сеть и SSH при установке

| Симптом | Решение |
|---|---|
| `No route to host` в первую секунду, потом пинг идёт | Вероятно, Pi «просыпается» из энергосбережения Wi-Fi (первые пакеты теряются). Повторите; лучше Ethernet |
| `REMOTE HOST IDENTIFICATION HAS CHANGED` | После переустановки системы изменился ключ: `ssh-keygen -R <IP>` |
| `Permission denied` | Логин `root` (а не имя хоста). Если образ собран без пароля root, вход возможен только по ключу: положите свой публичный ключ в `authorized_keys` на загрузочный раздел карты (он добавится при следующем запуске) или соберите образ с `--ssh-key` либо `SD_PASSWORD` |
| Связь пропадает при копировании больших файлов или при отключении USB-устройств | Просадка питания. Короткий кабель, блок 5.1 В / 2.5 А, Ethernet, не вынимайте USB при включённой Pi |

## Механика звучит не так

| Хочется | Параметр в `FX_ARGS` |
|---|---|
| Стук молоточков тише или громче | `--hammer-boost` (дБ) |
| Тихая игра без стука / со стуком | `--hammer-exp` больше / меньше |
| Больше или меньше живости в стуке | `--random` |
| Громче или тише педаль, резонанс | `--pedal-boost`, `--res-boost` |

В записи молоточков (`rel*.wav`) звук нарастает не мгновенно: заметный уровень появляется через 23–81 мс от начала
файла. Это свойство самих сэмплов, к задержке системы отношения не имеет. Сэмплы в сборке не обрезаются.
