# Proposal

## Why

Идентификатор установки создаётся случайно при первом включении (см. «Идентичность установки»), поэтому имя setup-сети и QR-коды устройства нельзя узнать на этапе сборки образа. QR-код, созданный при сборке, не может относиться ни к какому реальному устройству и по нему нельзя подключиться. Код имеет смысл только как принадлежность уже установленной копии exxpiano, которую пользователь распечатывает сам.

## What Changes

- QR-коды (подключение к setup-сети, открытие страницы setup, открытие страницы устройства) SHALL создаваться только web-интерфейсом установленного устройства из его постоянного installation ID.
- Web-страница SHALL предлагать скачать каждый код как PNG и SVG с именем файла, содержащим ID установки, а также распечатать страницу как наклейку. Другого способа получить код нет.
- Сборка SD-образа MUST NOT создавать QR-коды, наклейки или файлы с ними; удалить автономный скрипт `scripts/make-qr.py`.
- Код подключения к setup-сети остаётся доступным всегда: наклейку печатают заранее, а setup-сеть включается позже, когда у устройства нет сети.
- Исправить дымовой тест образа: образ монтируется только для чтения, поэтому веб-службе нужна записываемая `/tmp`, а проверка кода должна сравнивать SSID с реально сгенерированным ID, а не с фиксированным именем.
- Аппаратная проверка не требуется для этого изменения: поведение полностью покрывается автоматическими тестами и сборкой образа-заменителя. Проверка на реальной Raspberry Pi остаётся невыполненной.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `web-control`: скачивание QR-кодов на странице установленного устройства.
- `provisioning-and-upgrades`: сборка образа не создаёт QR-кодов и наклеек.

## Impact

- `pi/exxpiano-web.py`: ответ `/api/qr` дополняется PNG (base64) и именем файла.
- `pi/web/index.html`: ссылки скачивания PNG/SVG, обновлённые подсказки на русском и английском.
- Удаляется `scripts/make-qr.py`; зависимых документов и тестов нет.
- `scripts/sd-smoke-test.sh`: записываемая `/tmp`, проверка по сгенерированному ID.
- Формат образа, installation ID и конфигурация не меняются.
