Piano bank

Banks from a USB drive

Put SoundFont files (.sf2, .sf3) into the folder piano-banks of a USB drive (FAT32, exFAT or ext4), plug it in and import: the copy starts only when you press the button, and the drive is not needed afterwards.

MIDI files

Put MIDI files (.mid) into the folder piano-midi of a USB drive and import them: a file plays on the piano you have chosen, with the hammer, damper and pedal noises. The drive is not needed afterwards.

Touch

How the strength of a keypress turns into loudness. Adjust it to your keyboard; it takes effect immediately.

Piano mechanics

Hammer, damper, string resonance and pedal noises. Changes apply within a second.

Audio output

These changes need a restart of the synthesizer (about 45 seconds of silence while the banks load).

64 is the lowest FluidSynth accepts. Raise it if you hear clicks. The built-in jack rounds the period up by itself: see the real value on the Monitor tab.

Device name

With several devices, give each its own name: it is shown in the menu and in the browser tab, and the page opens at http://name.local:8080/. Lowercase letters, digits and hyphens.

Wi-Fi

Phone setup by QR code

Scan with the phone camera: the first code joins this device's setup network, the second opens this settings page. The codes belong to this installation and can be downloaded only here: save the PNG or SVG and print a sticker for the device. The join code works whenever the setup network is on.

Connect to a network

Choose the network and type its password. The Pi tries it for up to a minute and keeps the previous settings if it does not work.
