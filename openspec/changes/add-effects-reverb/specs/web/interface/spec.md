# Spec Delta

## MODIFIED Requirements

### Requirement: Применение настроек

Система SHALL валидировать запросы настройки, применять live-параметры немедленно и требовать отдельного явного перезапуска для настроек синтезатора.

#### Scenario: Live-настройка

- **WHEN** клиент изменяет чувствительность, механику, gain или эффекты допустимым запросом
- **THEN** система сохраняет настройку и применяет её без принудительной перезагрузки банков

#### Scenario: Настройка с перезапуском

- **WHEN** клиент изменяет выход, буфер или полифонию
- **THEN** система сохраняет настройку, но перезапускает синтезатор только после отдельного подтверждённого запроса

## ADDED Requirements

### Requirement: Раздел «Эффекты»

Web-интерфейс SHALL показывать отдельный раздел меню «Эффекты» с включением реверберации, ползунками «Количество», «Размер зала» и «Глушение» и предупреждением о нагрузке на процессор, а галочка реверберации MUST больше не показываться в разделе «Аудиовыход».

#### Scenario: Открытие раздела

- **WHEN** пользователь открывает раздел «Эффекты»
- **THEN** интерфейс показывает текущие значения реверберации из состояния устройства на выбранном языке

#### Scenario: Изменение без перезапуска

- **WHEN** пользователь двигает ползунок или переключает реверберацию
- **THEN** изменение применяется без кнопки перезапуска, а если устройство ответило, что нужен перезапуск, интерфейс показывает это так же, как для настроек аудиовыхода
