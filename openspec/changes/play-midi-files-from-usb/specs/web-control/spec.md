# Spec Delta

## ADDED Requirements

### Requirement: MIDI-файлы в web-интерфейсе

Web-интерфейс SHALL показывать MIDI-файлы на подключённом накопителе и в библиотеке, позволять импортировать, запускать, останавливать, повторять и удалять их, а также показывать состояние и позицию воспроизведения, не принимая от браузера путей файловой системы.

#### Scenario: Список и состояние

- **WHEN** пользователь открывает раздел MIDI-файлов
- **THEN** интерфейс показывает файлы накопителя, файлы библиотеки с длительностью и состояние воспроизведения (ожидание, воспроизводится с позицией, причина остановки)

#### Scenario: Запуск и остановка

- **WHEN** пользователь запускает импортированный файл и затем останавливает его
- **THEN** интерфейс показывает «воспроизводится» с растущей позицией, а после остановки «ожидание»

#### Scenario: Недопустимый запрос

- **WHEN** запрос называет файл, которого нет в списке, содержит путь, неизвестное действие или приходит без токена при включённой защите
- **THEN** API отклоняет его с безопасной ошибкой, не раскрывая внутренних путей

#### Scenario: Занятость

- **WHEN** идёт импорт или переключение банка
- **THEN** запуск воспроизведения и удаление отклоняются как конфликт, а текущая операция продолжается
