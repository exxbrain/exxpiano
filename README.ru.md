**Фортепиано, которое звучит.** exxpiano превращает Raspberry Pi (даже б/у Pi 3 A+ с 512 МБ) в цифровое пианино для любой USB MIDI-клавиатуры: образ записывается на карту, плата включается, всё настраивается с телефона. Без установки и без экрана на плате. Первая нота звучит не позже 15 с от включения (Pi 3 Model B).

> **Сделано для плат с 1 ГБ памяти.** Полный банк рояля (около 700 МБ, тот, что в видео ниже) рассчитан на плату с 1 ГБ, например Raspberry Pi 3 Model B; на ней он настроен и проверен. Уменьшенный банк `lite` сделан для того, чтобы плата с 512 МБ (Pi 3 A+) тоже играла.
>
> **Чтобы поиграть, компьютер не нужен.** После записи карты пианино работает само по себе: подключите клавиатуру и наушники, включите питание и играйте. Пианино запускается само; телефон нужен только чтобы менять настройки, а компьютер только чтобы записать карту.

## Запуск за 4 шага (ничего собирать не нужно)

Понадобятся Raspberry Pi 3, 4 или 5 (для Pi 5 ещё и USB-звуковая карта), карта microSD, блок питания для своей платы (**5.1 В / 2.5 А** для Pi 3, 5.1 В / 3 А для Pi 4, 5.1 В / 5 А для Pi 5), USB MIDI-клавиатура и наушники или колонки.

1. **Скачайте** ZIP для своей платы из [последнего релиза](https://github.com/exxbrain/exxpiano/releases/latest): `exxpiano-rpi-…-sd.zip`, один образ для Pi 3, 4 и 5 (Pi 5 нужна USB-звуковая карта).
2. **Запишите его на карту microSD** через [Raspberry Pi Imager](https://www.raspberrypi.com/software/): *Choose OS* → *Use custom* → ZIP как есть (распаковывать не нужно).
3. **Включите:** вставьте карту в Pi, подключите клавиатуру и наушники (разъём 3.5 мм или USB-звуковая карта) и подайте питание. Первый запуск идёт без сети. Пока грузится полный банк, играет небольшой **рояль-превью**: на Pi 3 Model B первая нота звучит не позже 15 с от включения (14,5 с по секундомеру), а полный банк — примерно через 32 с после превью. Пианино переходит на полный банк без паузы, в момент, когда отпущены все клавиши и педаль. Превью звучит проще: 3 слоя громкости, 22 кГц, а ноты дольше 3 с обрываются концом сэмпла.
4. **Откройте с телефона:** подключитесь к Wi-Fi сети **`exxpiano-Setup-<ID>`** (пароль **`exxpianosetup`**); web-интерфейс откроется сам или по адресу `http://10.42.0.1:8080/`. В его разделе **Wi-Fi** подключите Pi к домашней сети, затем откройте `http://exxpiano-<id>.local:8080/`. Пока у Pi нет сохранённых сетей, сеть настройки работает **5 минут** после включения (пока к ней подключён телефон, она не выключается): если не успели, выньте и снова вставьте питание. С кабелем Ethernet сети настройки нет: сразу откройте этот адрес.

Можно играть. Подробнее о сети настройки: [«Подключение к новой Wi-Fi»](docs/USING.ru.md#подключение-к-новой-wi-fi); и прочитайте «Питание» ниже. Собирать банки и образ самому нужно только разработчикам: [docs/BUILDING.ru.md](docs/BUILDING.ru.md).

## Возможности

- **Настоящий звук рояля:** банки SoundFont через FluidSynth плюс механика рояля (стук молоточков и демпферов, резонанс струн, стук педали), которую формат SF2 сам выразить не может. В готовых образах лежит Salamander Grand Piano V3 (Yamaha C5); любой другой банк `.sf2` / `.sf3` можно добавить с USB-накопителя и выбрать в web-интерфейсе, а у каждого банка свои запомненные настройки туше и механики.
- **Сделано для плат с 1 ГБ:** банк `full` (около 700 МБ) рассчитан на плату с 1 ГБ; плате с 512 МБ достаётся уменьшенный `lite`. Образ сам выбирает банк.
- **Готовый образ:** один ZIP для Raspberry Pi 3, 4 и 5 (64-битная Alpine Linux); первый запуск автономный и ничего не спрашивает. У Pi 5 нет разъёма 3,5 мм, она играет через USB-звуковую карту.
- **Автоматический выбор:** любая USB MIDI-клавиатура находится сама; звук идёт через USB-звуковую карту (малая задержка), если она есть, иначе через разъём 3,5 мм.
- **Настройка с телефона:** web-интерфейс для кривой чувствительности, механики, громкости, банков, звукового выхода, Wi-Fi (через собственную setup-сеть устройства и QR-код) и мониторинга (процессор, температура, питание, память, ошибки).
- **С USB-накопителя:** импорт звуковых банков и воспроизведение MIDI-файлов на выбранном рояле, с механикой.
- **Открытый и проверенный:** открытый код (скрипты MIT, звуки CC-BY, две демонстрационные записи CC BY-NC-SA) и сотни автоматических тестов; что не пробовалось на реальной плате, помечено.

Пока не пробовалось на реальном железе: импорт с USB-накопителя (см. «Проверено на» ниже).

## Что понадобится

| | |
|---|---|
| Raspberry Pi 3 или 4 либо Raspberry Pi 5 с USB-звуковой картой (один образ для всех трёх; Raspberry Pi 2 не поддерживается) | SD-карта с образом продукта |
| **Блок питания 5.1 В / 2.5 А (3 А для Pi 4, 5 А для Pi 5) и короткий кабель** | см. «Питание» — это не формальность |
| USB MIDI-клавиатура | «class compliant», драйверы не нужны |
| Наушники или колонки | разъём 3,5 мм у Pi 3/4 или USB-звуковая карта (задержка меньше; у Pi 5 только она) |

## Питание (читать обязательно)

Pi 3 очень чувствительна к питанию. Проверка:

```bash
vcgencmd get_throttled     # должно быть 0x0
```

Любое другое значение (например `0x50005`) означает, что напряжение просело. Последствия, которые мы наблюдали:
щелчки в звуке, пропадающий Wi-Fi и обрыв SSH при копировании больших файлов, перезагрузки при отключении USB-устройств.
Лечится **блоком 5.1 В / 2.5 А и коротким толстым кабелем** (до 1 м, сечение жил 20 AWG и толще, без выключателя).
Длинный тонкий шнур — самая частая причина.
Pi 4 нужен блок 5.1 В / 3 А, а Pi 5 — 5.1 В / 5 А (официальные блоки USB-C для этих плат).

## Проверено на

- **Raspberry Pi 3 Model B** (1 ГБ) с **образом на Alpine Linux** (версия после 1.10.22): загружается без сети, расширяется на карту, получает имя, все службы стартуют, полный банк загружается, KeyLab Essential 49 mk3 играет, обновление через `apk` работает; «Кампанелла» из MIDI-плеера, записанная на выходе, без клиппинга, разрывов и провалов звука. С этим образом ещё не проверены: Pi 3 A+, Pi 4 и Pi 5, setup-сеть, подключение USB-звуковых карт и накопителей на ходу.
- **Raspberry Pi 3 Model B** (1 ГБ) с полным банком на прежнем образе DietPi (1.10.22 и старше), клавиатурой Arturia KeyLab Essential 49 mk3 и штатным выходом 3.5 мм. **Pi 3 A+** (512 МБ) играет на уменьшенном банке `lite` (**проверен на реальной Pi 3 A+, работает**).
- **Raspberry Pi 5** (8 ГБ) с образом DietPi `rpi5` версии 1.10.21 (образ на Alpine на Pi 5 ещё не проверен) и USB-интерфейсом Zoom U-24: карта выбрана сама, с момента загрузки ни провалов звука, ни ошибок, полный банк загрузился. На ней пока не проверены: перевыбор карты при подключении и отключении, задержка целиком.

На других платах, клавиатурах и звуковых картах не проверялось. USB-звуковую карту я рекомендую; её задержка не измерялась. Полный список с версиями и цифрами: [docs/ABOUT.ru.md](docs/ABOUT.ru.md#проверено-на).

**Время запуска** (замер на Pi 3 Model B с полным банком): **первая нота не позже 15 с от включения** (14,5 с по секундомеру; пока загружается полный банк, примерно 37 с после запуска синтезатора, играет небольшой рояль-превью). Самый первый запуск свежей карты ещё расширяет раздел на всю карту и длится дольше; с версией 2.0 он не замерялся. Загрузка полного банка — это чтение 729 МБ с карты на 23 МБ/с, предел Pi 3, поэтому более быстрая карта не поможет.

## Выбор банка рояля

В образах два банка одного и того же рояля Salamander:

- `full` (около 700 МБ): 14 слоёв громкости, хвосты 12 с, для платы с 1 ГБ. **Не для 512 МБ.**
- `lite` (237 МБ): 6 слоёв громкости вместо 14, хвосты 9 с вместо 12 с, самая тихая нота громче (−12 дБ вместо −17 дБ), поэтому динамический диапазон немного меньше. На плате с памятью меньше 800 МБ (Pi 3 A+) он выбирается сам.

Ещё в образе есть `piano-preview.sf2` (24 МБ, 3 слоя, стерео 22 кГц, хвосты 3 с): он играет только пока загружается банк и как банк не предлагается.

Оба есть в разделе **«Банк рояля»** web-интерфейса. **«Использовать»** переключает рояль без перезапуска: пока загружается новый банк, играет превью (на Pi 3 Model B 17 с для `lite`, 38 с для `full`), так что можно продолжать играть, а если новый банк не загрузится, прежний возвращается сам. **«Удалить»** убирает неиспользуемый банк, чтобы освободить место: текущий банк, последний рабочий и банк механики не удаляются никогда, и отменить удаление нельзя. Не проверено на реальной Raspberry Pi: нажатие **«Удалить»** там; правила покрыты автотестами. Кривая чувствительности, громкость и уровни механики запоминаются для каждого банка.

Другие банки `.sf2` / `.sf3` можно импортировать с USB-накопителя (папка `piano-banks/`), так же и MIDI-файлы, чтобы сыграть их на рояле (папка `piano-midi/`). Импорт с USB-накопителя пока не пробовался на реальном железе. Подробности: [docs/USING.ru.md](docs/USING.ru.md#выбор-банка-рояля).
