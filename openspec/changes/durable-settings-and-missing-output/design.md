# Design

## Decisions

1. **Долговечная запись.** В `wifilib.write_secret`, `exxpianoconf.apply_updates` и `profiles.save`: `flush` и `fsync` временного файла до `os.replace`, затем `fsync` каталога (иначе после сбоя питания может вернуться старое имя). Ошибка `fsync` каталога только пропускается: файл уже целиком на месте, а редкая файловая система не умеет синхронизировать каталог. Файлы в `/run` (запросы, состояние) — в памяти, им `fsync` не нужен.
2. **Отсутствующий выход.** `Actions._audio_output` ищет в журнале синтезатора последнюю строку `audio output …` и последнее «no sound card found»; если второе позже — `device` = `None`, `missing` = `true`. Иначе, если карты из `CARD=` нет среди `cards()`, `missing` = `true` (так видно и вынутую карту, когда правило udev не перезапустило синтезатор). `output_card` для громкости не берёт отсутствующий выход.

## Risks / Trade-offs

- [`fsync` на карте занимает миллисекунды-десятки миллисекунд] → только при сохранении настроек, не на пути звука.
- [Правило udev на удаление USB-карты на реальной плате не проверено] → страница всё равно показывает правду по списку карт.
