# Proposal

## Why

Банки на карте занимают сотни мегабайт (`full` около 695 МБ, `lite` около 237 МБ), а удалить через web-интерфейс можно было только импортированные. Владельцу, который выбрал один банк, нужно освободить место и убрать лишнее из списка, не заходя на устройство по SSH.

## What Changes

- Кнопка «Удалить» у каждого банка библиотеки, а не только у импортированных: установленные пакетом или вручную банки из `BANK_DIR` удаляются так же, как импортированные.
- Запрет прежний: нельзя удалить текущий банк, последний рабочий (`PIANO_SF2_LAST_GOOD`) и банк механики; нельзя удалять во время переключения банка или импорта.
- Удаляется только обычный несокрытый файл, который сам каталог перечисляет (никаких путей, символических ссылок и имён за пределами каталога); файл сначала переименовывается в скрытое имя, потом стирается.
- Подтверждение с предупреждением, что отменить нельзя: вернуть банк можно только установкой заново или новой картой. Ответ API сообщает освобождённый объём.
- API: `POST /api/bank {"action": "delete", "id": "<банк>"}`; прежнее `POST /api/usb {"action": "delete"}` для импортированных остаётся.
- В списке банков показана память: всего, сколько может занять банк (за вычетом резерва системы и банка механики), свободное место на карте, полоса текущего банка и у каждого банка доля допустимого размера. `GET /api/state` получает `banks.memory`.
- Прежнее требование «MUST NOT удалять установленные банки через интерфейс» снимается: это решение владельца.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `banks/management`: удаление любого банка библиотеки, кроме используемых; сведения о памяти в списке банков.
- `banks/usb-import`: условие про установленные банки перенесено в управление банками.

## Impact

`pi/banklib.py` (`delete_installed`), `pi/exxpiano-web.py` (`delete_bank`, `/api/bank`), `pi/web/index.html`, тесты `tests/test_web.py`, README, troubleshooting. Проверено автотестами; на реальной плате кнопка не нажималась. Файл банка, установленный пакетом `exxpiano-soundfonts`, после удаления не восстановится сам: при обновлении пакета `dpkg` положит его обратно.
