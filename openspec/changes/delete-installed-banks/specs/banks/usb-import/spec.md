# Spec Delta

## MODIFIED Requirements

### Requirement: Удаление импортированного банка

Система SHALL позволять удалить импортированный банк, который не является текущим или последним рабочим. Правила удаления установленных банков описаны в управлении банками.

#### Scenario: Удаление неактивного импорта

- **WHEN** пользователь подтверждает удаление неактивного импортированного банка
- **THEN** система атомарно удаляет его файл и метаданные и обновляет каталог

#### Scenario: Попытка удалить активный банк

- **WHEN** выбранный импорт является текущим или последним рабочим fallback-банком
- **THEN** система отклоняет удаление и объясняет, что сначала нужно выбрать другой рабочий банк
