# Spec Delta

## Purpose

Первый запуск карты не требует никакого ввода на самом устройстве.

## ADDED Requirements

### Requirement: Консоль без запроса пароля

Образ SHALL показывать на локальной консоли информационный экран с ID установки, именем и адресами страницы управления вместо приглашения входа. Консоль MUST NOT запрашивать логин или пароль, MUST NOT показывать секреты и MUST NOT включать автовход. Администрирование SHALL оставаться доступным по SSH.

#### Scenario: Первый запуск с подключённым HDMI

- **WHEN** карта запускается впервые с подключённым монитором
- **THEN** вместо приглашения `login:` на экране информационный экран, который обновляется и не принимает ввод

#### Scenario: Устройство без сети

- **WHEN** у устройства нет адреса
- **THEN** экран называет setup-сеть этой установки и адрес страницы setup

#### Scenario: Сборка образа

- **WHEN** выполняется сборка или дымовая проверка образа
- **THEN** они проверяют наличие экрана и drop-in и отсутствие файла автовхода
