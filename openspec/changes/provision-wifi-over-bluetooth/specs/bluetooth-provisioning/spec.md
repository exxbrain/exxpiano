# Spec Delta

## Purpose

Эта возможность позволяет подготовить домашнюю Wi-Fi устройства через BLE с телефона, не подключая телефон к setup-сети самого устройства.

## ADDED Requirements

### Requirement: Обнаружение устройства по BLE

Во время разрешённого окна настройки устройство SHALL рекламировать BLE-сервис exxpiano и полный постоянный installation ID. Мобильный клиент SHALL показывать найденные устройства по этому ID и MUST NOT требовать ввода serial платы.

#### Scenario: Найдено несколько устройств

- **WHEN** рядом находятся несколько устройств exxpiano с открытым BLE-окном
- **THEN** мобильный клиент показывает каждое устройство с его полным installation ID и позволяет выбрать одно из них

#### Scenario: Bluetooth-адаптер отсутствует

- **WHEN** система запускается без доступного Bluetooth-адаптера
- **THEN** BLE-настройка помечается недоступной, а фортепиано и setup Wi-Fi продолжают запускаться

### Requirement: Ограниченное окно настройки

Устройство SHALL автоматически открывать BLE-настройку на ограниченное время, если сохранённых Wi-Fi-сетей ещё нет. После успешного сохранения сети BLE-настройка SHALL закрываться; повторное открытие SHALL требовать явной команды из доступного web-интерфейса или локального действия на устройстве. Одновременно SHALL обслуживаться не более одной provisioning-сессии.

#### Scenario: Первоначально ненастроенное устройство

- **WHEN** устройство без сохранённых Wi-Fi-сетей загружается с доступным Bluetooth-адаптером
- **THEN** BLE-настройка доступна в течение настроенного начального окна и затем автоматически закрывается, если сессия не активна

#### Scenario: Устройство уже настроено

- **WHEN** устройство с сохранённой Wi-Fi-сетью запускается без явной команды открытия BLE
- **THEN** provisioning-сервис не рекламирует возможность изменения сети

#### Scenario: Второй телефон подключается одновременно

- **WHEN** одна provisioning-сессия уже активна и другой клиент пытается начать настройку
- **THEN** устройство отклоняет вторую сессию без изменения сетевой конфигурации

### Requirement: Защищённая передача параметров Wi-Fi

Provisioning-сервис SHALL принимать SSID, признак скрытой сети и пароль только через зашифрованное BLE-соединение. Открытый пароль MUST NOT попадать в журнал, аргументы процессов, status-файлы или постоянное хранилище и SHALL удаляться из памяти сессии после передачи производного PSK Wi-Fi supervisor либо завершения сессии.

#### Scenario: Незащищённая запись характеристики

- **WHEN** клиент пытается передать параметры Wi-Fi без установленного зашифрованного BLE-соединения
- **THEN** устройство отклоняет запись и не создаёт запрос подключения

#### Scenario: Клиент отключился во время настройки

- **WHEN** BLE-соединение разрывается до принятия запроса Wi-Fi supervisor
- **THEN** устройство очищает данные незавершённой сессии и не меняет сохранённые сети

### Requirement: Настройка сети из мобильного клиента

Официальный мобильный клиент SHALL работать на Android и iOS, получать от выбранного устройства список видимых Wi-Fi-сетей, принимать открытую или защищённую либо скрытую сеть, отправлять запрос подключения и показывать итоговый статус. Успешный ответ SHALL содержать installation ID и доступные hostname или IP-адрес для последующего открытия web-интерфейса.

#### Scenario: Успешное подключение

- **WHEN** пользователь выбирает доступную сеть, вводит правильный пароль и устройство получает default route
- **THEN** приложение показывает успешное подключение и адрес устройства, а BLE-окно закрывается

#### Scenario: Неверный пароль или недоступная сеть

- **WHEN** Wi-Fi supervisor не подтверждает подключение за отведённое время
- **THEN** приложение показывает диагностируемую ошибку, прежняя конфигурация сохраняется и setup Wi-Fi остаётся доступным как fallback

### Requirement: Совместимость Raspberry Pi

BLE-настройка SHALL поддерживать встроенный Bluetooth Raspberry Pi 3 и 4. На Raspberry Pi 2 она SHALL работать с явно поддерживаемым USB Bluetooth-адаптером; его отсутствие MUST NOT менять остальные возможности образа.

#### Scenario: Raspberry Pi 2 без USB Bluetooth

- **WHEN** универсальный образ запускается на Raspberry Pi 2 без совместимого USB Bluetooth-адаптера
- **THEN** пользователь по-прежнему может выполнить настройку через уникальную setup Wi-Fi

#### Scenario: Raspberry Pi 2 с USB Bluetooth

- **WHEN** поддерживаемый USB Bluetooth-адаптер доступен на Raspberry Pi 2 до открытия окна настройки
- **THEN** устройство предоставляет тот же BLE-протокол и пользовательский поток, что и Raspberry Pi 3/4
