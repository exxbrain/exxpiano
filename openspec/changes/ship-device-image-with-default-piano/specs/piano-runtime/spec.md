# Spec Delta

## REMOVED Requirements

### Requirement: Привязка карты к плате

**Reason**: Serial используется только для идентичности и прослеживаемости сборки; запуск синтезатора не должен зависеть от совпадения или доступности serial текущей платы.

**Migration**: Удалить `DEVICE_LOCK`, проверку serial перед запуском и связанные с блокировкой поля API и реестра. Образ запускается на любой совместимой плате и при недоступном serial.
