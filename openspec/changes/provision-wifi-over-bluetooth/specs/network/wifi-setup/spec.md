# Spec Delta

## ADDED Requirements

### Requirement: Единый владелец настройки Wi-Fi

Система SHALL передавать проверенные запросы из web- и BLE-интерфейсов одному Wi-Fi supervisor. Только supervisor SHALL изменять `wpa_supplicant`, переключать режим `wlan0`, проверять default route и выполнять откат. Ошибка BLE-подключения или отсутствие Bluetooth MUST NOT отключать автоматическую setup-сеть и captive portal.

#### Scenario: BLE-запрос принят

- **WHEN** BLE-служба передаёт валидированный запрос подключения с SSID, производным PSK и признаком скрытой сети
- **THEN** Wi-Fi supervisor выполняет существующую атомарную попытку подключения и публикует результат с идентификатором запроса

#### Scenario: Одновременные запросы из web и BLE

- **WHEN** Wi-Fi supervisor уже выполняет изменение сети и второй transport отправляет другой запрос
- **THEN** второй запрос получает состояние busy и не изменяет выполняемую операцию или сохранённую конфигурацию

#### Scenario: BLE-настройка завершилась ошибкой

- **WHEN** запрос из BLE не приводит к рабочему default route
- **THEN** supervisor восстанавливает прежнюю конфигурацию и возвращает setup Wi-Fi тем же способом, что и для web-запроса
