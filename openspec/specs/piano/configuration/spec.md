# Конфигурация исполнения

## Purpose

Эта возможность безопасно хранит и применяет параметры инструмента и устройства, сохраняя формат файла окружения служб и пользовательские профили.

## Requirements

### Requirement: Валидация изменяемых параметров

Система SHALL принимать через управляющий интерфейс только известные параметры, приводить их к объявленным типам и отклонять значения вне допустимых диапазонов до изменения файла конфигурации.

#### Scenario: Допустимое изменение

- **WHEN** клиент передаёт известный параметр с корректным типом и значением в допустимом диапазоне
- **THEN** система сохраняет нормализованное значение

#### Scenario: Неизвестный или недопустимый параметр

- **WHEN** клиент передаёт неизвестное имя, нечисловое значение или значение вне диапазона
- **THEN** система возвращает ошибку и оставляет конфигурацию неизменной

### Requirement: Атомарное сохранение

Система SHALL обновлять конфигурацию атомарной заменой файла, сохранять несвязанные строки и комментарии и оставлять файл доступным для чтения systemd.

#### Scenario: Частичное обновление

- **WHEN** меняется один разрешённый параметр
- **THEN** новое значение появляется целиком, а остальные настройки и комментарии сохраняются

#### Scenario: Ошибка записи

- **WHEN** атомарное сохранение не может завершиться
- **THEN** предыдущий файл остаётся пригодным для чтения и временный файл не считается активной конфигурацией

### Requirement: Области применения настроек

Система SHALL различать настройки MIDI-моста, live gain и настройки, требующие перезапуска синтезатора.

#### Scenario: Изменение механики

- **WHEN** изменяется чувствительность или уровень механики
- **THEN** MIDI-мост подхватывает значение без перезапуска FluidSynth

#### Scenario: Изменение общей громкости

- **WHEN** изменяется gain при работающем FluidSynth
- **THEN** система сохраняет значение и пытается применить его через закрытый локальный командный канал

#### Scenario: Изменение аудиоустройства

- **WHEN** изменяется аудиоустройство, размер буфера, число периодов, полифония или реверберация
- **THEN** система сохраняет значение и сообщает, что для применения требуется перезапуск синтезатора

### Requirement: Профили инструмента и устройства

Система SHALL хранить параметры тембра, чувствительности, громкости и механики отдельно для каждого банка, а параметры буфера — отдельно для каждого аудиоустройства.

#### Scenario: Возврат к ранее использованному банку

- **WHEN** пользователь снова выбирает банк с сохранённым профилем
- **THEN** система восстанавливает настройки этого банка без изменения аппаратных параметров устройства

#### Scenario: Возврат к аудиоинтерфейсу

- **WHEN** пользователь снова выбирает аудиоинтерфейс с сохранённым профилем
- **THEN** система восстанавливает параметры буфера этого интерфейса
