## MODIFIED Requirements

### Requirement: Атомарное сохранение

Система SHALL обновлять конфигурацию атомарной заменой файла, сохранять несвязанные строки и комментарии и оставлять файл в формате `KEY=value` или `KEY="value"`, который init-скрипты служб читают как окружение без выполнения команд из файла.

#### Scenario: Частичное обновление

- **WHEN** меняется один разрешённый параметр
- **THEN** новое значение появляется целиком, а остальные настройки и комментарии сохраняются

#### Scenario: Ошибка записи

- **WHEN** атомарное сохранение не может завершиться
- **THEN** предыдущий файл остаётся пригодным для чтения и временный файл не считается активной конфигурацией

#### Scenario: Значение со служебными символами оболочки

- **WHEN** сохранённое значение содержит `$`, обратные кавычки, `;` или кавычки
- **THEN** служба получает это значение буквально, и никакая команда из файла конфигурации не выполняется
