## ADDED Requirements

### Requirement: Проверка и публикация сборок Alpine

CI SHALL запускать быстрые автоматические тесты для push и pull request. Публичные CI-артефакты и релизы MUST NOT содержать отдельные пакеты `.apk` или ZIP/TAR.GZ-инсталлятор для установки поверх готовой ОС. Полный образ Alpine SHALL формироваться отдельно при изменениях конвейера или выпуске. Релизная сборка SHALL брать пакеты Alpine только из закреплённой в репозитории версии ветки и зеркала и MUST проверять подписи индекса и пакетов закреплёнными в репозитории ключами Alpine до создания образа. Тег `v<VERSION>` SHALL запускать формирование GitHub Release, а релизный тег MUST совпадать с файлом `VERSION`. GitHub Release SHALL иметь английский заголовок с названием продукта, версией и списком поддерживаемых моделей Raspberry Pi и английское описание состава, установки, первого запуска и проверки контрольных сумм. Он SHALL содержать универсальный ZIP-образ, README, машиночитаемый манифест и файл SHA-256 контрольных сумм и MUST NOT публиковаться при ошибке сборки или проверки образа.

#### Scenario: Проверка обычного изменения

- **WHEN** изменение не затрагивает формирование полного образа
- **THEN** CI запускает быстрые тесты и не запускает полный образный конвейер

#### Scenario: Выпуск образа

- **WHEN** оператор публикует тег, соответствующий `v<VERSION>`
- **THEN** CI создаёт GitHub Release с заголовком и описанием и прикладывает один ZIP с Alpine, приложением и обязательными банками, README, манифест и файл контрольных сумм

#### Scenario: Проверка закреплённой основы Alpine

- **WHEN** CI начинает релизную сборку по тегу версии
- **THEN** он использует закреплённые ветку и зеркало Alpine и продолжает только при успешной проверке подписей ключами из репозитория

#### Scenario: Ключ подписи пакетов недоступен

- **WHEN** релизная сборка не получила секрет ключа подписи пакетов проекта
- **THEN** сборка завершается ошибкой, и GitHub Release не публикуется

#### Scenario: Ошибка формирования образа

- **WHEN** сборка банков, пакетов, образа или его автоматическая проверка завершается ошибкой
- **THEN** GitHub Release с этим образом не публикуется

#### Scenario: Несовпадающий релизный тег

- **WHEN** tag build использует версию, отличную от `VERSION`
- **THEN** публикация релиза завершается ошибкой до прикрепления артефактов
