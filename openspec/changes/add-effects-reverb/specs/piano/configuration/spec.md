# Spec Delta

## MODIFIED Requirements

### Requirement: Области применения настроек

Система SHALL различать настройки MIDI-моста, live gain, эффекты, применяемые на ходу, и настройки, требующие перезапуска синтезатора.

#### Scenario: Изменение механики

- **WHEN** изменяется чувствительность или уровень механики
- **THEN** MIDI-мост подхватывает значение без перезапуска FluidSynth

#### Scenario: Изменение общей громкости

- **WHEN** изменяется gain при работающем FluidSynth
- **THEN** система сохраняет значение и пытается применить его через закрытый локальный командный канал

#### Scenario: Изменение эффектов

- **WHEN** изменяется включение реверберации, посыл или параметры зала
- **THEN** система сохраняет значение и применяет его без перезапуска синтезатора (параметры зала через командный канал, посыл через MIDI-мост), а если применить не удалось, сообщает, что требуется перезапуск

#### Scenario: Изменение аудиоустройства

- **WHEN** изменяется аудиоустройство, размер буфера, число периодов или полифония
- **THEN** система сохраняет значение и сообщает, что для применения требуется перезапуск синтезатора
